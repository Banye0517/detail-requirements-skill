# 工单字段与结构

## 表内结构

第一张「详情需求表」包含产品信息、详情屏和主图建议。每屏采用三行。

| 列 | 屏内容行 | 来源行 | 参考说明行 |
|---|---|---|---|
| A | 屏号或原表映射 | 合并归属本屏 | 合并归属本屏 |
| B | 本屏任务 | 合并归属本屏 | 合并归属本屏 |
| C | 消费者主标题 | 合并归属本屏 | 合并归属本屏 |
| D | 副标题、图标卖点、tips | 合并归属本屏 | 合并归属本屏 |
| E | 画面执行与理由，9:16 | 合并归属本屏 | 合并归属本屏 |
| F | 运营待确认 | 合并归属本屏 | 合并归属本屏 |
| G | 参考图1 | 图1的商品超链接 | 图1借鉴与本品应用 |
| H | 参考图2 | 图2的商品超链接 | 图2借鉴与本品应用 |
| I | 参考图3 | 图3的商品超链接 | 图3借鉴与本品应用 |

原始卖点保留原文，消费者文案独立填。主标题6–12字，副标题8–16字；图标短句不超过10字。模板的操作提示可以比文案长。

## 参考《商详工单规范12》的对应关系

以下是用户历史模板右侧示例区的坐标。实际填报时先查看文件，不能直接覆盖这些地址。

| 原位置 | 意义 | 通用工单位置 |
|---|---|---|
| T3:AC7 | 申请信息、产品名、图、参考链接、注意项 | 表头信息和运营待补 |
| U10 | 首屏标志、卖点、名称、icon、副文案 | 第1屏C、D及F |
| U11 | 购买理由 | 第2屏C、D |
| U12:U15 | 特点、价值、场景，可增减 | 中间卖点与场景各屏 |
| U16 | 产品档案、小字、用法、注意事项 | 最后一屏 |
| Y10:AC16 | 参考图 | 每屏G、H、I及图下来源 |
| U20:U24 | 五张主图建议 | 主图区 |

图下链接使用商品名称作为显示文本，底层超链接目标为完整商品直链。表内应显示品牌和商品名，不能把图片地址当商品链接。
